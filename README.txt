پروژه تمرینی طراحی وب باشگاه ورزشی بابایی

مهم: کد امتحان در یک فایل است: index.html
تمام HTML و CSS سایت، فرم و صفحه تماس با ما در همین فایل قرار دارند.

فایل‌های جانبی این بسته برای نمایش دموی دو دکمه‌ای هستند:
- org.html: صفحه سفید با دو دکمه خاکستری
- copy.html: کد کامل index.html با دکمه کپی

برای نمایش سایت در index.html، تصاویر امتحان را در مسیرهای زیر قرار بده:
- pic/logo.png
- pic/sport/s1.jpg
- pic/sport/s2.jpg
- pic/sport/s4.jpg

اگر نام عکس‌های امتحان فرق دارد، فقط src تصاویر را در index.html اصلاح کن.

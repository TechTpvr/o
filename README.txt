پروژه تمرینی طراحی وب — باشگاه ورزشی بابایی

فایل‌ها:
- org.html : صفحه شروع با دو دکمه
- index.html : صفحه اصلی سایت باشگاه

تصاویر:
تصاویر امتحان را در مسیرهای زیر قرار دهید:
- pic/logo.png
- pic/sport/s1.jpg
- pic/sport/s2.jpg
- pic/sport/s4.jpg

اگر اسم تصاویر داخل پوشه امتحان فرق داشت، مقدار src همان تصویر را در index.html تغییر دهید.
برای دیدن سایت، فایل org.html را در مرورگر باز کنید و «مشاهده ظاهر سایت» را بزنید.
این پروژه فقط HTML و CSS داخلی دارد و برای اجرا به نصب یا سرور نیاز ندارد.

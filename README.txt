پروژه طراحی وب باشگاه ورزشی بابایی

فایل‌ها:
- org.html: صفحه شروع با دکمه‌های «بازدید از سایت» و «کپی کردن کد»
- index.html: ظاهر سایت باشگاه
- code.html: نمایش کد اصلی index.html و دکمه کپی
- contact.html: صفحه تماس با ما با شماره‌ها و نام مدیر

تصاویر پوشه Pic امتحان را در این مسیرها قرار دهید:
- pic/logo.png
- pic/sport/s1.jpg
- pic/sport/s2.jpg
- pic/sport/s4.jpg

اگر نام یا پسوند تصاویر امتحان متفاوت است، src تصاویر را در index.html تغییر دهید.
فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ برای بارگیری آن اتصال اینترنت لازم است.
برای GitHub Pages، فایل‌ها را در ریشه مخزن قرار دهید و مسیر سایت را باز کنید.
